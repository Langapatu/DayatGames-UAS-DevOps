## Catatan teknis

- Semua cover menggunakan frame CSS 4:5 dan `object-fit: contain`, sehingga artwork tidak dipotong.
- Badan kartu memakai tinggi fleksibel yang seragam; judul dua baris, genre, harga, dan tombol tetap sejajar.
- URL aset diberi versi berdasarkan waktu modifikasi file agar browser tidak menampilkan cover lama dari cache.
- `hero_image` sementara memakai aset 4:5 yang sama sebagai latar dengan perlakuan khusus pada area hero.
- Logo tetap berasal dari folder `Logo`; tidak ada logo baru atau cover pengganti yang diunduh.
